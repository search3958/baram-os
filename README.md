# 自作カーネルプロジェクト

## 概要
UEFI対応のx86_64/ARM64両対応の自作カーネル。マウスポインター、キー入力、ディスプレイ出力をサポート。

```
/workspace
├── kernel/          # カーネルソースコード
├── bootloader/      # ブートローダー設定
└── docs/            # ドキュメント
```
